영상 용량 줄이기 · iPhone

여러 영상을 목표 용량(10MB, 20MB, 100MB 또는 직접 입력 1MB~2,000MB) 이하의 MP4로 한 번에 줄이는 iPhone 앱입니다. 영상 길이에 맞춰 해상도와 프레임을 자동으로 고르고, 만든 파일의 실제 크기가 목표 이하일 때만 결과로 남깁니다.

자주 묻는 질문

결과가 정말 목표 용량 이하인가요?
네. 1MB를 1,000,000바이트로 계산하고, 만든 파일의 실제 바이트 수를 재서 목표를 넘으면 다시 만들거나 실패로 알려 드립니다. 목표를 넘는 파일은 결과로 남기지 않습니다.
"이 길이면 최소 ○MB가 필요해요"가 나와요.
영상이 길어 가장 낮은 화질(360p)로도 목표 안에 들어가지 않는 경우입니다. 목표 용량을 알려 드린 값 이상으로 직접 입력해 주세요.
어떤 형식으로 저장되나요?
MP4(H.264 영상, AAC 소리), 최대 1080p·60fps입니다. Windows PC, 웹 사이트, 메일에서 열리는 형식입니다. HDR 영상은 일반(SDR) 색으로, 세로 영상은 회전 정보 없이 똑바로 선 화면으로 저장합니다. 공간 비디오는 일반(2D) 영상이 됩니다.
메일이나 사이트에 올렸는데 용량 초과라고 나와요.
본문까지 합쳐 한도를 정하거나 여러 파일의 합계 한도가 있는 곳이 있습니다. 한도보다 조금 작게 직접 입력해 다시 줄여 주세요. 받는 곳의 규칙은 바뀔 수 있어 특정 서비스의 통과를 보장하지는 않습니다.
변환 중에 다른 앱으로 가도 되나요?
끝날 때까지 화면을 켜 두는 것이 가장 빠르고 확실합니다. 변환이 멈추면 앱으로 돌아와 '이어서 다시 시작'을 눌러 주세요.
무료로 몇 개까지 쓸 수 있나요?
목표 이하로 줄이는 데 성공한 영상 기준으로 처음 3개까지 무료입니다. 이미 목표보다 작아 줄일 필요가 없던 영상과 실패한 영상은 세지 않습니다. 이후에는 '제한 없이 이용하기'를 한 번 구매하면 계속 쓸 수 있습니다(구독 아님). 설정 화면에 구매와 구매 복원 버튼이 있습니다.
원본 영상은 어떻게 되나요?
원본은 읽기만 하고 바꾸거나 지우지 않습니다. 결과는 항상 새 파일입니다.
